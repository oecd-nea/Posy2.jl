Modelling Concepts

Start with study configuration and input workbooks when setting up a study, then snapshot building when defining the system, then optimisation when solving, and finally querying and exporting when you need results.

  • Study Configuration: input paths, input modes, discount rate, CO2 price, and optional DC power flow
  • Input Workbooks: technology parameters and hourly time series
  • Building a Snapshot: simulations, carriers, nodes, builders, costs, tags, and interconnections
  • Extending Posy2: custom builders, naming, and tags
  • Optimising a Snapshot: objectives, DC power flow and extraction
  • Querying a Snapshot: capacities, balances, costs, and prices
  • Tags and Post-Processing: which tags appear in reports and annual metrics
  • Exporting Results: Workbook reports and saved snapshots
